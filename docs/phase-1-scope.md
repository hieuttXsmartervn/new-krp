## Constraints

- Frontend implementation only at this stage.
- Use client-side validation and demo feedback.
- Do not implement fake authentication, account creation, approval decisions, or email delivery.
- Do not connect to PostgreSQL or modify its schema.
- Preserve the legacy page layout and information hierarchy while modernizing individual UI components.
- Backend APIs and business rules will be mapped from the existing .NET implementation when source access is available.
